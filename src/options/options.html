Encoding

Error correction

Higher levels survive more damage but produce denser codes. Lowered automatically if a URL is too long.

Strip tracking parameters

Removes utm_*, fbclid, gclid and similar before encoding — a shorter URL makes a sparser, easier-to-scan code.

Extra parameters to strip

Your own names, separated by commas. Useful when a site adds tracking the built-in list doesn't cover.

When a code gets dense

Long URLs force a choice between error correction and a code your phone can actually read.

Selected text

Link to the selected text

Builds a link that scrolls the reader to the passage you highlighted. Ignored by browsers older than Firefox 131.

Show first

Which reading of a selection the popup opens on.

Link precision

Matching the whole passage is exact; matching only its ends encodes far less and keeps the code sparse.

Country code for local numbers

Added to numbers written without one, like 918-555-4351. Leave it blank to encode them bare and let the scanning phone decide.
